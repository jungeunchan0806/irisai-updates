# 관리자 앱 1.2.0

Android APK는 자체 WebView에서 관리자 아이디·비밀번호 로그인 화면을 바로 엽니다. 관리 패널과 다른 호스트, ChatGPT 인증 경로로 이동하지 않습니다. 네트워크 오류는 앱 내 재시도 화면에서 처리합니다. 키 복사는 제한된 쓰기 전용 클립보드 브리지를 사용합니다.

Windows EXE는 Edge 또는 Chrome 앱 창을 전용 프로필로 열어 기존 브라우저의 로그인·이동 상태를 이어받지 않습니다. Edge 또는 Chrome 설치가 필요합니다. 접속 주소는 익명 방문 가능한 관리자 로그인 화면이며, 관리 API는 별도의 관리자 세션을 검사합니다.

관리자 계정과 구독 데이터, 8~128자 비밀번호 정책은 기존 서버를 사용합니다. ChatGPT 계정은 앱 실행·관리자 로그인·배포 파일 다운로드에 사용하지 않습니다. 최초 설정 코드·비밀번호·서명 개인키는 포함하지 않습니다.

서명 재료는 이 저장소 밖에서 `build.py` 인자로 전달합니다. `public/downloads/admin-1.2.0/`에 로그인 없이 받을 수 있는 APK·EXE를 배포합니다. Android와 Windows 실기기 실행 여부는 검증 보고서에 별도로 기록합니다.
