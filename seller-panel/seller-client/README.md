# 판매자 클라이언트 UI 2.1.0

기존 APK의 `assets/panel.html`과 Windows 클라이언트의 HTML 리소스를 이 파일로 교체해 빌드합니다. `BshackDevice` 및 로컬 HTTP 브리지 규약은 유지했습니다. 서버에 구매자 키 `revoke`, `restore`, `delete` 기능이 포함되어야 합니다.

기존 앱의 서명키 및 빌드 소스가 이 저장소에 없으므로 새 판매자 APK/EXE는 아직 배포하지 않았습니다. 다른 키로 서명하거나 앱을 삭제하면 기기 인증 키가 달라질 수 있으므로, 원래 빌드 프로젝트에서 기존 서명으로 업데이트해야 합니다.
