단독판 2.2.0 기본 화면으로 복구됐다면 오른쪽 위 투명 버튼 → 업데이트 확인 → 2.2.4 확인을 누르고 다운로드가 끝난 뒤 앱을 다시 여세요. 2.2.4에서는 같은 높이의 상단 중앙 투명 버튼으로 메뉴를 엽니다.

한국어·영어 메뉴와 도움말의 기능 이름을 **Anti AFK**로 바꿨습니다. 연결이 끊기면 새 입력은 대기하며, 게임 상태가 다시 갱신되면 켜 둔 기능이 재개됩니다.

이전에는 시작 성공을 저장하려면 UI가 두 차례 응답하고 로컬 인증 모듈까지 준비되어야 했습니다. 이 버전은 화면이 실제 배치되고 정상적인 엔진 응답을 받으면 시작 성공을 기록합니다. 해당 조건을 충족하기 전에 앱이 종료되면 기존 설치본의 복구 기능이 동작할 수 있습니다.

실제 기기의 이전 실패 원인은 확인되지 않았습니다. 자동 검사는 이전 2.2.3의 실패 기록이 있는 2.2.0에서 새 패치를 적용하고 세 차례 재시작한 뒤 상단 중앙 버튼을 확인합니다. 이 릴리스는 오토골 단독판용입니다.
