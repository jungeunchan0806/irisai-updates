# BSHACK / Iris 오토골 2.3.0 통합판

**설치 파일: `BSHACK-Autogoal-2.3.0.apk` 하나만 받으세요.**
기존 오토골 APK와 같은 서명입니다. 기존 오토골 앱을 삭제하지 말고 업데이트 설치하세요.
더세븐 별도 서명 APK나 공식 앱 위에는 같은 서명으로 설치되지 않습니다.

- 기존 오토골 엔진, HWID·인증, 진단, 업데이트 확인, 언어 전환, UI 숨김을 유지했습니다.
- 기존 Iris UI, 상단 중앙 투명 열기 영역, `discord.gg/bshack` 링크를 유지했습니다.
- 더세븐의 에임봇, 오토닷지, 자동 발사, 길게 눌러 발사, 엑스레이, AFK 방지, 셰이드 중앙 조준, 나니 모드, 빈 핀, 적 탄약 표시, 화면 흔들림 끄기, FPS 표시·제한 설정을 기존 Iris UI에 연결했습니다. 원본 오토팜은 비활성화했습니다.
- IrisAI 0.0.9의 모델과 기본 사거리 기반 전투 정책, 벽 회피·막힘 복구, 로비·결과 화면 반복 플레이를 Android용으로 옮겼습니다.

**오토팜 사용:** 게임에서 브롤러를 선택한 다음, 큰 Iris UI → `Iris 오토팜` → `오토팜 설정`에서 같은 브롤러를 지정하고 켜세요. 메뉴를 닫으면 동작합니다. 기존 오토골 인증이 필요합니다. 게임의 기본 조작 버튼 위치를 사용합니다. 오토골이 공을 처리하는 동안 오토팜 입력은 멈추고, 게임을 벗어나거나 인증이 만료되면 꺼집니다.

이번에는 모델·실행 라이브러리가 추가되어 APK 업데이트가 한 번 필요합니다. 이후 UI·엔진 패치는 앱의 기존 업데이트 확인 기능으로 받을 수 있습니다. 기존 2.2.x 자동 패치 채널은 변경하지 않았습니다. 첨부된 작은 패치 ZIP·해시·검증 JSON은 직접 설치할 파일이 아닙니다.

더세븐 원본 C++ 소스는 제공되지 않아, 두 APK에서 호환성이 확인된 기존 네이티브 모듈을 재사용했습니다. 모델 파일은 원본 Iris 소스와 같습니다. Mac의 브롤러 자동 교체·OCR 대기열 기능은 포함하지 않습니다. 게임 언어·화면 구성이 원본 템플릿과 다르면 일부 로비·결과 화면에서 입력을 멈출 수 있습니다.

서명·파일 보존·16KB 정렬, 원본 ARM64 설정 함수, 실제 ONNX/OpenCV 녹화 화면 분석, Android 15·16의 UI·인증·업데이트·입력 중지 검사를 수행합니다. 실제 삼성 Android 17 기기의 접속 및 친선전투는 테스트하지 못했습니다.
