기존 통합판에서 상단 중앙 투명 버튼 → 업데이트 확인 → 확인을 누른 뒤 앱을 완전히 종료하고 다시 여세요. 로딩이 멈추면 큰 UI → 오류 확인 → 내용 복사를 누르세요. 복사 버튼은 확인이 끝나면 활성화됩니다.

'앱 실행 기록'은 현재 앱 프로세스가 일반 앱 권한으로 읽을 수 있는 최근 로그에서 오류 종류와 줄 수를 보여줍니다. 개발자 옵션, USB 디버깅 또는 버그 신고 파일 준비가 필요하지 않습니다. 원문 로그나 주소는 새 항목에 포함되지 않으며 결과는 자동 전송되지 않습니다. 기기에서 로그를 읽을 수 없거나 알려진 유형이 없을 때는 해당 상태를 표시합니다.

이 릴리스는 멈춤 원인을 찾는 진단 업데이트입니다. 게임 서버와 통신하는 코드가 로그를 남기지 않으면 여기에도 표시되지 않을 수 있습니다. 실제 사용자 기기의 로비 진입 여부는 미확인입니다.
