# BSHACK 통합판 2.3.2 · 초기화 순서 수정

기존 2.3.0 통합 APK(2.3.1 패치 적용 포함)에서 **상단 중앙 투명 버튼 → 업데이트 확인 → 확인**을 누른 뒤 앱을 완전히 종료하고 다시 실행하세요. 로딩 화면에서도 Iris UI가 열리면 적용할 수 있습니다. APK 재설치·데이터 삭제는 필요 없습니다. 아래 ZIP은 앱 전용 패치이므로 직접 설치하지 마세요.

기존 코드는 추가 모듈의 API 주소가 만들어지면 초기화가 끝났다고 판단했습니다. 실제로는 초기화 작업이 계속되는 중에도 설정 적용과 Iris 게임 함수 연결이 시작될 수 있었습니다. 실제 완료 신호와 모듈 진행률 100%를 함께 확인하도록 수정했습니다. 초기화가 끝나면 기존 기능과 대기 중인 설정이 이어집니다.

기존 오토골·BSHACK 기능·Iris 오토팜·연결 복구 보호·UI·중앙 투명 버튼·디스코드·HWID 인증·업데이트를 유지합니다. 원본 게임 파일·서버 통신·APK 서명은 바꾸지 않습니다. ‘오류 확인’의 features 항목에 모듈 진행률과 초기화 완료 여부가 표시됩니다. 이 진행률은 게임 서버 로그인 성공 여부가 아닙니다.

실제 Frida CModule에서 기존 조기 준비 판정 결함을 재현한 뒤 수정했습니다. Android 15·16 자동 검사와 기존 설치본 검증기를 통한 패치 적용·반복 재시작 검사를 통과해야 게시됩니다. 사용자 폰의 서버 연결 멈춤은 직접 재현하지 못했으므로, 이 패치로 로비 진입이 해결되는지는 적용 후 확인이 필요합니다.

계속 멈추면 큰 UI → 오류 확인 → 내용 복사 결과를 확인해야 합니다. 단독 오토골 2.2.x 업데이트 채널에는 이 패치를 배포하지 않습니다.
