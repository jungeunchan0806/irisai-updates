## 받을 파일

**`IrisAutoGoal-BrawlStars-70.757-panel3-test-newkey.apk`** 하나를 받으세요. 약 1.97GB인 **실제 게임 APK**이며, 이전 `packaging2-test.apk`의 Iris 모듈을 교체했습니다.

**설치 제한:** 이전 APK의 서명용 개인키를 현재 작업환경에서 찾지 못해 새 키로 서명했습니다. 기존 수정본·진단 앱·공식 앱 위에 덮어쓰는 업데이트는 불가능합니다. APK에서 이전 개인키를 추출할 수도 없습니다. 기존 게임 삭제나 데이터 초기화는 이 릴리스가 수행하지 않습니다. 게임 진행 상태 보존 여부를 확인하지 않은 채 기존 앱을 삭제하지 마세요.

## 포함된 기능

- 오토골 ON → 게임 자체 화면 읽기 → 제공된 Iris 모델로 공·플레이어·골대 인식 → 이동·슈팅 판단 → 게임의 기존 내부 입력 메서드 호출
- 다시 OFF, 직접 게임 조작, 앱이 뒤로 가거나 포커스를 잃으면 자동 입력 중지
- 새 큰 설정창, 오른쪽 위 투명 열기 영역(오토골 버튼 가로·세로 각각 2배), 전체 UI 숨김·복원
- 한국어·영어, `https://discord.gg/bshack` 링크. 라이선스 항목은 제거했습니다.
- OFF/백그라운드 반복 작업 중지, 추론 텐서·이미지 버퍼 재사용
- 유효한 분석 결과로 시작한 입력이 중간에 시간 초과로 취소되던 경로 수정. 오래된 분석·OFF 이후 입력·지나치게 늦은 뗌 동작은 계속 차단합니다.

게임 화면에서 **오토골 OFF**를 누르면 모델을 읽고 켜집니다. 조작 위치가 다르면 오른쪽 위 투명 영역을 눌러 **조작 위치**에서 이동·공격·가젯 위치를 지정하세요. 이 버전의 기본 상태는 OFF입니다.

**스트리머 모드:** 본인 화면에는 UI가 보이고 녹화·공유에만 사라지는 요청 동작은 구현하지 못해 비활성화했습니다.
