# BSHACK 통합 2.3.1 · 연결 복구 보호

기존 앱의 **중앙 위 투명 버튼 → 업데이트 확인 → 확인**으로 적용하고 앱을 완전히 종료한 뒤 다시 실행하세요. 시작 시 업데이트 안내에서도 적용할 수 있습니다. APK 재설치는 필요 없습니다.

이 릴리스의 ZIP은 앱이 검증하여 읽는 패치입니다. ZIP을 APK처럼 설치하지 마세요.

적용 대상: 2.3.0 기반 BSHACK 기능·Iris 오토팜 통합판. 다른 판의 패치는 서명된 기반 식별자로 차단됩니다.

연결 복구 보호 추가: 네트워크 끊김·전투 상태 멈춤 감지 시 새 자동 입력을 보류하고, 새 전투 상태가 안정되면 재개합니다.
재접속 전의 공·이동 경로·전투 참조를 폐기합니다. 직접 OFF로 끄면 복구 후에도 OFF를 유지합니다.
Iris 오토팜도 연결 대기 중 입력을 해제하고 오래된 화면 분석 결과를 버립니다.
기존 중앙 투명 버튼·Iris UI·디스코드·인증·업데이트를 유지합니다.
서버 공격 차단·서버 AFK 퇴장 방지·서버 중단 중 플레이 보장은 불가능합니다. 로컬 상태 감지는 서버 응답 확인이 아니며 모든 레드와이파이를 감지하지는 못합니다.
업데이트 후 앱을 완전히 종료하고 다시 실행하세요.

검증 범위: 연결 단절·멈춘 틱·화면 포커스·네트워크 전환을 주입한 테스트, 실제 Frida/Java UI 브리지, 기존 설치본 검증기를 통한 서명 패치 적용 및 반복 재시작. Android 15·16 에뮬레이터 검사를 통과한 경우에만 자동 게시됩니다. 실제 게임 서버 공격·친선전·Samsung Android 17 실기기 검증은 수행하지 않았습니다. 서버나 게임 자체의 종료를 억지로 막지 않습니다.
